# RetailIQ — AI-Powered Retail Demand & Profit Intelligence

RetailIQ is an end-to-end retail analytics and AI project designed to forecast demand,
analyze revenue and profitability, identify inventory risk, and provide business recommendations.

## Project workflow
Dataset → Data Cleaning → SQL Analytics → Forecasting → ML Risk → Recommendations → Dashboard → AI Assistant

## Dataset
Use the M5 Walmart retail dataset. Place these files in `data/raw/`:
- sales_train_validation.csv
- calendar.csv
- sell_prices.csv
